API reference

Jobmesh exposes a free, keyless JSON API over a live, de‑duplicated index of job postings aggregated from dozens of ATS and job‑board platforms. Every role links back to its original application page.

Base URL   https://jobmesh.world

No key required. Responses are JSON. Rate limits are generous for normal use; a Premium key raises the per‑request result cap.

Also on RapidAPI — the same API is published on RapidAPI (free Basic plan, 1,000 req/mo; Pro plan, 100,000 req/mo).

Search jobs

GET /jobs

Filtered, paginated full‑text search over open postings.

ParameterDescription
keywordRole or skill, matched in title and description (e.g. data engineer).
companyFilter by employer name.
locationFree‑text location (e.g. Berlin).
countryISO‑2 country code (e.g. DE, US, NG).
platformSource platform (e.g. greenhouse, lever).
workplace_typeremote / hybrid / onsite.
employment_typee.g. Full-time, Contract.
categoryBroad domain (e.g. Engineering).
levelSeniority (e.g. Internship, Junior / Entry, Senior).
sinceOnly jobs posted within the last N days.
limitResults per page. Up to 50 (free), 1000 with a Premium key. Default 30.
offsetPagination offset. Default 0.

Examples

# curl
curl "https://jobmesh.world/jobs?keyword=data%20engineer&country=DE&limit=5"
# Python
import requests
r = requests.get("https://jobmesh.world/jobs", params={
    "keyword": "data engineer", "country": "DE", "limit": 5})
results = r.json()["results"]
// JavaScript (fetch)
const r = await fetch(
  "https://jobmesh.world/jobs?keyword=data+engineer&country=DE&limit=5");
const { results, total } = await r.json();

Pagination — page with offset/limit; has_more stays true while rows remain. Counts — above 10,000 matches, total comes back as 10000 with total_capped: true (show it as “10,000+”). De‑duplication — one role posted on several sources collapses to a single result; group_size and other_source_urls expose the duplicates.

Premium key: pass ?api_key=... or the header X-API-Key to lift the per‑request cap from 50 to 1000 results.

Export & feeds

GET /export.csv

Filtered search as CSV (same filters as /jobs). Without a key — a free sample of the 1,000 most recent rows, flagged with an X-Jobmesh-Sample: true header and the note “Free sample — full export with Jobmesh Premium”. With a Premium key — the full filtered set.

GET /export.json

Agency feed. Without a key — a free sample of the 1,000 most recent rows, with "sample": true, "sample_limit": 1000 and a "note" field. With a Premium key — the full feed, paginated with offset/limit.

# free sample (no key) — up to 1,000 rows
curl "https://jobmesh.world/export.json?country=DE&limit=1000"

# full export (Premium)
curl -H "X-API-Key: ..." "https://jobmesh.world/export.csv?country=DE"

Jobs, companies & changes

GET /jobs/{id}

A single posting by its uid.

GET /jobs/by-url?url=...

A posting by its source or apply URL.

GET /companies · /companies/{name}

Employers with open-job counts; a single employer with its latest roles.

GET /filter-values · /suggest?q=...

Distinct values per filter field; prefix-first title/company suggestions.

GET /facets

Result counts per filter value for the current query — build faceted filters without extra calls.

GET /changes?since=<cursor>

New, modified and closed postings since a cursor (each row carries change_type and is_open); page with the returned cursor.

Extra /jobs filters: posted_after=YYYY-MM-DD, seen_within=N (days), has_salary=true, include_closed=true, platform.

Bulk .gz feeds (Premium)

GET /export/jobs.ndjson.gz · /export/jobs.csv.gz

The full open index, gzipped, regenerated after each ingest cycle. Premium key required.

Rate limits

240 requests/minute without a key, 2,400/minute with a Premium key (rolling 60‑second window). Every response carries X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset and X-Request-Id; over the limit returns 429 with Retry-After.

Index & coverage

GET /stats

Headline numbers: open postings, companies, boards, grouped duplicates, last refresh. Add Accept: application/json for JSON.

GET /sources

The full 78‑platform registry: per‑platform status, live open count and the exact reason any platform is not yet active.

GET /coverage

Per‑platform open‑job counts and last‑fetch health.

MCP server (for AI agents)

POST /mcp

Jobmesh is listed on the official MCP Registry as io.github.TatianaTchouakam/jobmesh. Any MCP client can connect over Streamable‑HTTP and call three tools:

search_jobsSearch the index by keyword, location, country, level, category or remote‑only.
index_statsCurrent totals for the index.
source_coveragePer‑platform coverage and status.
 
// connect an MCP client to:
https://jobmesh.world/mcp   (transport: streamable-http)
